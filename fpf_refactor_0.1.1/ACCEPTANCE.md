# Приёмка на целевом устройстве

Версия: 0.1.0-rc.1. Выполняйте действия через интерфейс и reload; инструменты разработчика не нужны. Для iPad/iPhone сначала используйте статический режим из README: все вкладки в одном Safari. Для другой платформы укажите режим, ОС и браузер в результате.

Не очищайте данные сайта внутри одной проверки восстановления. До первого испытания можно использовать отдельную новую папку/origin; IndexedDB прототипа `ttscore-prototype-0.1.0` общая для всех папок одного origin.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Создайте 2×2, личные встречи из 3 партий; откройте Umpire и зрителя | Team 0:0; зритель ждёт данных |
| 2 | Подготовьте встречу | Имена пары видны, очки и партии пусты; зритель видит ожидание спортсменов |
| 3 | Подтвердите прибытие, затем начните партию | До начала очки пусты и партии 0:0; после начала очки 0:0 |
| 4 | Запишите очко, перезагрузите страницу, нажмите Undo | Вернулся предыдущий счёт; одно сохранённое Undo доступно после reload |
| 5 | В «Проверка восстановления» отключите связь; запишите очко | Локальный счёт сохраняется, публичное состояние не объявляется новым до связи |
| 6 | Включите связь | Зритель получает актуальные сохранённые показания |
| 7 | Вызовите «Сбой следующего сохранения» и попробуйте записать очко | Видно сообщение об отказе; прежний счёт сохраняется. Следующее обычное действие работает |
| 8 | Закончите две партии 11:0 в пользу одного спортсмена | Итог личной встречи 2:0; табло удерживает 11:0 и счёт партий 1:0 (стороны могут быть переставлены) |
| 9 | Освободите счётчик | Цифры скрыты; итог и отчёт сохранены; Team ещё 0:0 |
| 10 | Нажмите «Потерять ответ о принятии», затем подтвердите завершение | Видно потерянное подтверждение; Team получает только одну победу |
| 11 | Нажмите повторную синхронизацию или дождитесь автоматической | Появляется подтверждение принятия; Team по-прежнему имеет одну победу |
| 12 | В Administrator нажмите Undo; повторите синхронизацию старого Umpire | Team 0:0, первая пара снова текущая; старый результат отмечен отменённым |
| 13 | Подготовьте новую попытку | Пустые индикаторы; старые очки не подставлены под новую попытку |
| 14 | Откройте второй Umpire одновременно | Видно «Управление уже открыто». Зритель при этом разрешён |
| 15 | Сохраните отчёт | Получен JSON; закрытие/смена роли не уничтожает текущую сессию |

Дополнительно: в новой встрече проверьте ручной итог без отчёта, его Undo и подготовку после отзыва старого счётчика. Если регистрация отозвана, старый учёт можно сохранить и явно закрыть его передачу; новый допуск не выдаётся старому пакету автоматически.

Форма результата: устройство / ОС / браузер / режим / номер шага / ожидаемое / фактическое / снимок экрана при необходимости. Успех внутреннего Chromium-прогона не считается вашей приёмкой.

# ttScore prototype 0.1.0-rc.1

Первая исполняемая поставка по новой архитектуре. Включает 2×2, bestOf 3/5/7, семь фаз, раздельные спортивные и экранные значения, один Undo после reload, локальные сохранения и пакет завершения, Team/зрителя, автоматический и ручной результат, Team Undo, квитанции, регистрацию автора и проверку старых запросов. Локальная демоверсия запускается статически; принимающий сервер — Node.js с SQLite либо demo RTDB Emulator.

Добавлены автоматические проверки, UI-прогоны, fault controls, инструкции запуска и полевой приёмки. Прежние архитектура и предметная модель приложены без изменения их версии; расхождения реализации явно описаны.

Это ограниченный прототип, не функционально полный преемник RC8. Полевая приёмка отсутствует; production-сервис не развёрнут. Ограничения: KNOWN_ISSUES.md, проверки: VERIFICATION.md.
